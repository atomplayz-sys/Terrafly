# TerraFly Project Ownership Pack

This folder is documentation-only. TerraFly runtime behavior was not modified.

## Start here

1. `TerraFly_Source_to_System_Atlas.pdf` - understand the problem, evidence states, both workflows, calibration, 3D, request flows, files, artifacts, claims and live proof.
2. `TerraFly_Zero_to_Ownership_Bootcamp.pdf` - assign the six roles, follow the minimal learning path, prepare real data, rehearse the oral exam and pass the judge-readiness gate.
3. Read/edit the matching `.md` sources when the project changes.

## Supporting evidence

- `SOURCE_LINE_INDEX.md` - implementation and test anchors.
- `RESOURCE_VERIFICATION_TABLE.md` - 40 checked learning resources.
- `CLAIMS_LEDGER.md` - proved, partial, blocked and future claims.
- `INCONSISTENCIES_AND_LIMITATIONS.md` - code/docs/UI mismatches and scientific limits.
- `diagrams/*.mmd` - editable diagram sources; matching PNGs are embedded in the PDFs.
- `screenshots/*-annotated.svg` - editable live screenshot callouts; originals and flattened PNGs are preserved.
- `rendered-pages/inspection-report.json` - page, blank-page and hyperlink audit.
- `tools/build_ownership_pack.py` and `tools/inspect_ownership_pack.py` - reproducible PDF/visual build and inspection.

## Audited result

- Atlas: 33 A4 pages, no blank pages.
- Bootcamp: 25 A4 pages, no blank pages, 41 clickable external links.
- Complete-page contact sheets were inspected after Poppler rendering.
- Application evidence used in the pack: 40 passing backend tests, 10 passing frontend tests, production build, DEM Terrain smoke, real CUDA DAV2 Large inference, synthetic calibration-gate smoke, artifact-hash verification and live browser operation.

These checks prove the packaged software path on the audited computer. They do not prove real-world Photo AI height accuracy.
